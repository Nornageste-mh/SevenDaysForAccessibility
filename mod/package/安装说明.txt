一句话说明
--------------------------------------------------------
让读屏软件朗读游戏里的文字：剧情旁白、主角「我」的台词、
配角台词，以及选项。有配音的台词**默认也朗读**（本作配音是日文，
读屏用户只听到语音等于这一句没有信息）；嫌吵可在配置里关掉，
关掉后仍可用 Backspace 重读。

语音后端自动按可用性挑选：
  1. Tolk        装了就用（支持 NVDA / JAWS / SuperNova / ZoomText）
  2. NVDA        没装 Tolk 但有 NVDA 就用这个
  3. 争渡读屏     只装争渡（ZDSR）就用这个 —— 走争渡自己的语音
  4. SAPI        Windows 内置语音，不装任何读屏也能出声
启动后看日志里的「语音后端: xxx」就知道用了哪个。
本版**没有**做「运行中切换后端」的功能键，要换后端请改配置后重启游戏。

【版本号怎么看】发布名是 v0.1.0.0，BepInEx 日志与配置文件里显示成 0.1.0.0，
  是同一个版本。
  版本号字段必须能解析成版本号：带字母的写法（比如 0.1.0a）会被判定
  "version is invalid" 并**静默跳过整个插件** —— 表现是模组完全没加载、
  游戏里一片安静，极难排查。要表达「第一版修订」请用第四位数字，如 0.1.0.1。

【本版有什么】首个可用版。
  · 台词：说话人 + 正文逐句朗读；旁白不加前缀；有配音的台词默认也念（可关）。
  · 选项：出现时播报「共 N 个选项。1，…。2，…。按数字键选择。」，
    按 1-9 直接选，选完播报「已选择，…」。
    （本作的选项按钮是运行时生成的，读屏定位不到，所以只能靠编号选。）
  · 限时选项：会播报「这是限时选项」，并按 0 立刻沉默。
    **倒计时改不了**（原因见【技术说明】），沉默走的是游戏自己的超时分支。
  · 历史回看：H 打开、上下键逐条朗读、回车播放该条语音、Esc 关闭
    （游戏原本只能用鼠标滚轮上滑打开，而且列表里的条目不是可聚焦控件）。
  · 存读档：F5 / F9 打开，或用 Esc 菜单进；槽位会念日期、说话人、正文。
  · 界面导航：标题页、Esc 菜单、设置页、存读档页、游戏的「是 / 否」确认框
    都能用 Tab + 上下键 + 回车操作；设置页 6 个滑条会念名字和百分比。
  · 开机健康提示页：整页没有任何可点控件，模组会主动播报
    「健康提示页，连按两次空格键进入游戏。」
  · 启动时播报一句按键提示；Backspace 随时重读最近一句。


========================================================
 安装（把文件拷进游戏目录，没有安装程序）
========================================================

补丁是运行时挂载的，不修改任何游戏文件，所以安装就是「拷文件」。

【第 1 步】找到游戏目录
  本作的游戏目录比一般游戏**再深一层**：
    <Steam>\steamapps\common\我与你共度的七日\game\
  也就是有 The seven days i spent with you.exe 的那一层。
  外层那个 SevenDaysLauncher.exe 只是启动器，**不要**装到它那一层。
  （Steam 里也可以：库 → 右键游戏 → 管理 → 浏览本地文件，然后进 game\。）

【第 2 步】把本文件夹里的东西全部拷进去
  保持目录结构不变，拷完应该长这样：

    <游戏目录>\game\
      The seven days i spent with you.exe   ← 游戏自带，不动
      winhttp.dll                           ← 本次新增
      doorstop_config.ini                   ← 本次新增（里面有一行指向 mono-bcl）
      .doorstop_version                     ← 本次新增
      nvdaControllerClient.dll              ← 本次新增
      changelog.txt                         ← 本次新增（BepInEx 自带说明）
      BepInEx\                              ← 本次新增，整个文件夹
        core\          （16 个文件，一个都不能少）
        plugins\
          SevenDaysForAccessibility.dll     ← 模组本体
          nvdaControllerClient.dll          ← 冗余副本，放着无妨
        mono-bcl\      （22 个 dll，**绝对不能删**）
        patchers\      （空目录，BepInEx 需要）

  四条容易踩的坑：
    · winhttp.dll、doorstop_config.ini、.doorstop_version 必须在
      **游戏根目录**（game\），不能放进 BepInEx\ 里
    · BepInEx\core\ 里的 16 个文件一个都不能少
      （BepInEx.Preloader.dll 是 doorstop_config.ini 指定的入口）
    · **BepInEx\mono-bcl\ 不能删，doorstop_config.ini 里的
      dll_search_path_override = BepInEx\mono-bcl 也不能改。**
      本作自带的 Mono 基础类库被裁剪过（mscorlib 缺 Module.GetPEKind、
      System.Core 缺 IGrouping`2.get_Key），BepInEx 5 原样装会直接崩在预加载器。
      这一套是 Mono 项目的开源类库（MIT），不含任何游戏内容。
    · nvdaControllerClient.dll 放游戏根目录 —— Mono 查找 DLL 时
      先看应用目录，放这儿最稳

【第 3 步】启动
  · 从 Steam 正常启动（不要直接双击 exe，Steam 版需要 Steam 在跑）
  · 第一次启动会慢 10-30 秒，BepInEx 在生成 config 和缓存，正常

【第 4 步】确认装好了
  打开 <游戏目录>\BepInEx\LogOutput.log，应该能看到：

      Preloader finished
      Loading [我与你共度的七日 A11y Reader 0.1.0.0]
      语音后端: NVDA
      [a11y] loaded v0.1.0.0 (Mono, BepInEx 5, 轮询式，无 Harmony)

  进游戏后应该听到：
      「健康提示页，连按两次空格键进入游戏。」
      「《我与你共度的七日》无障碍补丁已加载。空格推进对话，退格键重读，
        H 键历史回看，Esc 打开菜单，选项按数字键。」


========================================================
 如果之前装过别的 BepInEx 模组
========================================================

只需要两个文件：

    SevenDaysForAccessibility.dll  → <游戏目录>\BepInEx\plugins\
    nvdaControllerClient.dll       → <游戏目录>\

**不要**覆盖对方已有的 winhttp.dll 和 BepInEx\core\，版本冲突反而会让游戏打不开。
但本作多一个前提：对方的 doorstop_config.ini 里要有
    dll_search_path_override = BepInEx\mono-bcl
并且 BepInEx\mono-bcl\ 里那 22 个 dll 要齐全 —— 否则 BepInEx 起不来。
只用 SAPI 的话 nvdaControllerClient.dll 可以不装。


========================================================
 卸载
========================================================

删掉游戏目录下这些（全部是本模组新增的）：

    winhttp.dll
    doorstop_config.ini
    .doorstop_version
    changelog.txt
    nvdaControllerClient.dll
    BepInEx\            （整个文件夹，含 mono-bcl）

**只删 winhttp.dll 就足以让模组完全失效**，游戏立刻恢复原样。
存档在 %USERPROFILE%\AppData\LocalLow\RErevue_studio\The seven days i spent with you\，
卸载不会碰到它。


========================================================
 朗读什么 / 不朗读什么
========================================================

[会朗读]
  · 剧情文本：旁白、主角「我」、配角
  · 有配音的台词 —— **默认也朗读**，可在配置里关掉
  · 选项内容（公告编号）
  · 选择结果（「已选择，…」）
  · 面板开合、界面变化（「存档界面已打开。第 1 页，共 3 页。」）
  · 存档槽 / 读档槽的日期、说话人、正文

[不会朗读]
  · 画面 / 立绘 / CG / 视频（不做口述）
  · 打字机逐字动画（整行一次念完）
  · 设置页「语言选择 / 配音」两个下拉框的行名（游戏里那是图片文字）


========================================================
 按键
========================================================

  数字键 1 - 9      选择对应编号的选项
                    —— 必须用它，因为游戏原本的选项按钮是运行时生成的，
                       读屏无法定位（实测单批最多 3 个，1-9 够用）

  数字键 0          限时选择里「立刻沉默」
                    = 游戏自己的超时分支（选最后一项），不会扩大可达范围
                    可在配置里改键或关闭

  Backspace         重读当前这一句
                    （有配音的台词也会被记下来，按它可以让 TTS 念一遍文字）

  H                 打开历史回看（游戏原本只能用鼠标滚轮上滑）
                    打开后：上 / 下 = 上一条 / 下一条，Home / End = 首尾，
                    回车 = 播放该条语音，Esc = 关闭
                    可在配置里改键

  F5 / F9           打开存档 / 读档界面（可在配置里改键）
                    打不开时先按 Esc 把菜单关掉 —— 有面板开着时热键不生效

  空格 / 回车       推进对话（游戏原有）
  Ctrl / S          快进（游戏原有，快进时不朗读；停快进时补念最后一句）

【重要】以下按键游戏原生占用，模组不会去抢，也不要拿它们当重读键：
  A      自动模式
  S      快进
  Ctrl   快进
  空格 / 回车 / 小键盘回车 / 鼠标下滚   推进
  Esc    菜单 / 返回
  鼠标上滚   历史回看
  鼠标右键   返回

  重读键 / 历史回看键 / 存读档键都可以在配置里改成任意 KeyCode 名称，
  留空则关闭对应功能。


========================================================
 菜单 / 存档 / 设置 / 确认框的键盘导航
========================================================

游戏原本这些界面几乎只能鼠标点，现在可以纯键盘操作并朗读：

  Tab              进入 / 退出导航模式（进入时朗读「第几组，共 N 项」）
  上 / 下          上一项 / 下一项
  左 / 右          调整滑条（每按一次朗读新数值）
  回车 / 空格      激活 —— 按钮则点击，开关则切换
  Home / End       跳到第一项 / 最后一项
  PageUp/PageDown  切换面板组

朗读内容示例：
    「重写此生，按钮。1 / 6」
    「存档槽 3，空，回车保存到这里，按钮。4 / 13」
    「读档槽 2，2026-08-29 11:23:30，汐萝，已经拉钩约定了！…，回车读取，按钮。3 / 14」
    「文本显示速度，滑条，50%。12 / 19」
    「窗口模式，开关，关」

★ 对话中导航模式会自动退出
  本作没法拦游戏自己的「回车/空格推进」（原因见【技术说明】），
  在对话里开导航会让空格既推进又点控件。所以一进入对话，导航模式自动退出。
  对话里请用 1-9 选项、Backspace 重读、H 历史回看。

★ 只导航最上层面板
  一次扫描可能同时看到对话框、快捷菜单、存读档页等好几组控件。
  默认只进入最上层那一组，按 PageUp / PageDown 切换。

★ 退出前二次确认
  标题页的「退出游戏」会先问一次，再按一次才真的退出；
  剧情里的「返回标题」游戏自己会弹确认框，模组不会重复问。

★ 历史回看不是普通面板
  历史回看的条目本身不是可聚焦控件（游戏里是纯文本列表），
  所以模组给它做了专用浏览模式：打开后上下键逐条念，回车播放该条语音，
  这时 UiNav 的 Tab 导航会自动退出。

========================================================

  1. NVDA 必须在游戏启动前就已经在运行（用 SAPI 则不需要）
  2. 必须从 Steam 正常启动（本作没有免 Steam 的试玩版）

========================================================
 配置
========================================================

首次启动游戏后生成：

    <游戏目录>\BepInEx\config\sevendays.a11y.reader.cfg

用记事本打开，改完保存，重启游戏生效。

  [朗读]
  朗读有配音的台词 = true
      本作的刻意默认：有配音也念。配音是日文，读屏用户听不出内容。
      关掉后只放语音（仍进重读缓冲，Backspace 可以补读）。

  朗读时带上说话人 = true
      朗读时前面加上「汐萝，」「我，」这样的名字。旁白不加。

  朗读选项 = true
      出现选项时朗读全部选项
  数字键选择选项 = true
      用 1-9 选择选项

  沉默按键 = 0
      限时选择里立刻沉默，不必等倒计时走完。留空则关闭。

  重读按键 = Backspace
      重读当前句的按键。填 KeyCode 名称，留空关闭。

  语音后端 = 自动
      用哪个后端朗读。默认「自动」按 Tolk → NVDA → 争渡 → SAPI 的顺序
      挑第一个可用的。可填：自动 / Tolk / NVDA / 争渡 / SAPI（写 ZDSR 也认）。
      钉死某一个主要用来排查问题（例如填 SAPI 就能确认系统语音这条路通不通）；
      注意钉死之后**不会**自动降级，那个后端不可用就彻底没声了。
      本版没有「运行中切换后端」的功能键，改了要重启。

  快进停止时补念当前句 = true
      按住 Ctrl/S 快进时不朗读，松开后把最后一句补念一遍。

  [界面导航]
  菜单键盘导航 = true
      上面那套 Tab 导航的开关。

  按屏幕位置排序控件 = true
      导航顺序按控件在屏幕上的位置排（先上后下、同一行先左后右），
      让「第几项」和画面对得上。

  只导航看得见的控件 = true
      只把画面上真正能看到、能点到的控件纳入导航。
      只有在发现正常按钮被误排除时才需要关掉。

  退出前二次确认 = true
      标题页「退出游戏」的二次确认开关。
  退出确认对象名 = Exit
      哪些控件需要那道二次确认，按 Unity 对象名精确匹配（本作实查是 Exit）。
      多个名字用逗号分隔，留空关闭。
  排除的对象名 =
      不想让它出现在导航里的控件，按对象名精确匹配，逗号分隔。

  [其它]
  启动时播报 = true
      进游戏时播报一句按键提示。
  界面诊断日志 = false
      把每次扫到的控件、面板状态、热键命中情况写进 LogOutput.log。
      排查「某个控件定位不到」「热键没反应」时打开；排查完请关掉，日志会很大。
  历史回看按键 = H
  存档界面按键 = F5
  读档界面按键 = F9
      三个热键，填 KeyCode 名称，留空则关闭对应功能。


========================================================
 出问题了怎么办
========================================================

1) 完全没有声音
   · 打开 <游戏目录>\BepInEx\LogOutput.log，找这一行：
        语音后端: xxx
     - "Tolk (...)"  → 走 Tolk
     - "NVDA"        → 走 NVDA
     - "争渡读屏（ZDSR）" → 走争渡
     - "SAPI"        → 没检测到读屏，用的系统语音
     - "无"          → 四个后端都不可用
   · 完全没有 LogOutput.log → BepInEx 没起来：
     - winhttp.dll 是不是在 game\ 里（exe 旁边）？
     - doorstop_config.ini 的 enabled 是不是 true？
     - BepInEx\mono-bcl\ 那 22 个 dll 还在吗？doorstop 里的
       dll_search_path_override 是不是 BepInEx\mono-bcl？
     - 有没有 Preloader finished 这一行？没有的话看 BepInEx\preloader_*.log
   · 日志里写着 "version is invalid" → 插件版本号非法，请反馈，这是打包 bug
   · SAPI 也不响：系统「设置 → 时间和语言 → 语音」里装中文语音，
     可以用「讲述人」试听确认系统语音能出声
   · 想确认某个后端单独能不能用：把配置「语音后端」填成 Tolk / NVDA / 争渡 / SAPI
     再启动一次，日志会直接给出这个后端自己的结论

2) 游戏打不开 / 黑屏
   · 删掉 <游戏目录>\winhttp.dll，游戏立刻恢复原样
   · 或者打开 doorstop_config.ini，把 enabled = true 改成 false

3) 开机健康提示页按空格没反应
   · 这一页要**连按两次空格**（第一次显示内容，第二次进标题）
   · 如果按了没动静：先点一下游戏窗口（模组不抢焦点，但游戏要窗口在前台）

4) 选项出现后按空格，选项被直接选掉了
   · 这是游戏自己的焦点行为。模组在选项出现时会清一次选中项，
     但如果焦点被别处抢回来仍可能误选 —— 选项出现后**只用数字键**选

5) 历史回看 / 存读档热键打不开
   · 只在「游戏场景里 + 没有别的面板打开」时生效。
     先按 Esc 把菜单关掉再按 H / F5 / F9
   · 也可以 Esc 菜单 → Tab 导航 → 选「保存游戏 / 读取游戏」

6) 限时选择卡住不动
   · 按「沉默按键」（默认 0）可以直接继续

7) 朗读和配音同时响
   · 这是默认行为（有配音的台词也念）。想只放语音就把
     配置「朗读有配音的台词」关掉


========================================================
 技术说明（给愿意看的人）
========================================================

· 加载器：BepInEx 5.4.23.5（Unity Mono 版，winhttp.dll 代理注入）
· 朗读通道：Tolk / NVDA Controller Client / 争渡读屏（ZDSRAPI）/ SAPI，
  按可用性挑选。NVDA Controller Client 为官方 x64 构建，许可证 LGPL-2.1，
  允许随程序分发。争渡那一档**不随包分发**任何争渡文件（专有软件），
  由玩家自己安装争渡。
· **本作没有用 Harmony**，全部靠每帧轮询游戏自己的公开状态（轮询式）。
  原因：游戏安装在含中文的路径下时，Harmony/MonoMod 给多数方法打补丁会抛
  `ExecutionEngineException: String conversion error: Illegal byte sequence
   encounted in the input`。实测 10 个候选补丁点里只有 3 个能挂上
  （Backlog.AddLog / DataController.LoadData / DialogueUGUI.OnLoadSaveData），
  同一份 DLL 走 ASCII 路径时 15 个全挂 —— 补丁数量随安装路径变化，不可交付。
  代价：拦不住游戏自己的推进、也改不了限时选择的倒计时；换来的是
  **在任何安装路径下行为一致**。
· **BepInEx\mono-bcl\ 是干什么的**：本作自带的 Mono 基础类库被裁剪过
  （mscorlib.dll 只有 2.68 MB，缺 Module.GetPEKind；System.Core.dll 缺
  IGrouping`2.get_Key），BepInEx 5 预加载器一进去就要调这两个 API，原样装会抛
  `MissingMethodException: Module.GetPEKind`。发布包因此附一整套 Mono 类库
  （Mono 项目的开源实现，MIT，不含任何游戏内容），并用 UnityDoorstop 的
  dll_search_path_override 指向它。**删掉或改动都会让 BepInEx 起不来。**
· 第三方组件：本包除本模组外还带了 BepInEx、UnityDoorstop（winhttp.dll）、
  HarmonyX、Mono.Cecil、MonoMod、NVDA Controller Client 与那套 Mono 类库，
  它们的许可证与来源说明都在 licenses\ 目录里（BepInEx 5 / HarmonyX /
  Mono.Cecil / MonoMod / Mono 类库为 MIT，UnityDoorstop 与 NVDA Client
  为 LGPL-2.1）。**请不要删除 licenses\ 目录**，那是再分发的合规要求。
· 工作方式：运行时读取游戏状态（UIManager / Backlog / DataController /
  DialogueUGUI / Config 等），**不修改任何游戏文件**
· 不写注册表，不动系统目录，所有文件都在 <游戏目录> 内
· 判定是否有配音：BacklogData.VoiceFileName 是否为空
· 游戏版本：Unity 2021.3.31f1，Mono 后端，64 位

已实机验证（开发机，NVDA，游戏装在含中文的路径下）：
  健康提示页 → 标题页导航 → 新游戏 → 台词逐句与说话人 / 有配音台词朗读 /
  选项公告 + 数字键选择 / 历史回看逐条与语音 / 存档槽与真实保存 /
  读档槽与真实读档（含确认框）/ 设置页滑条名字与百分比 /
  退出确认框 / 关掉补丁（改名 winhttp.dll）后游戏照常运行
