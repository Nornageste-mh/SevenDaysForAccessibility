Why these files are shipped with this patch
-------------------------------------------
The game's own Mono class library is trimmed (mscorlib lacks Module.GetPEKind,
System.Core lacks IGrouping`2.get_Key), so BepInEx 5 cannot preload against it.
UnityDoorstop's dll_search_path_override points Mono at BepInEx/mono-bcl, which
holds a complete, unmodified set of Mono class library assemblies. They contain
no game content and are not derived from the game binaries.
